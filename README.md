# KrishiLink

KrishiLink is a modern agriculture marketplace platform where farmers can post crops and buyers can show interest in purchasing them. The platform connects farmers and buyers directly with a clean, user-friendly interface.


# Live Website  
https://assignment-10-krishilink-zarin.netlify.app/


# Key Features

- **Farmer Crop Management**  
  Farmers can add, update, and delete their crop posts with detailed information such as price, quantity, and location.

- **Interest Request System**  
  Buyers can send interest requests for crops, including quantity and custom messages.

- **Role-Based Access Control**  
  Farmers cannot send interest requests on their own crops, and buyers can send only one interest per crop.

- **Interest Management Dashboard**  
  Farmers can view all received interest requests and accept or reject them with real-time UI updates.

- **Authentication with Firebase**  
  Secure login, registration, and logout using Firebase Authentication.

- **Responsive Design**  
  Fully responsive UI optimized for mobile, tablet, and desktop devices.


## 🛠️ Technologies Used

- **Frontend:** React, Tailwind CSS, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Firebase
- **Hosting:**  
  - Client: Netlify  
  - Server: Vercel


# Deployment

- Frontend deployed on **Netlify**
- Backend API deployed on **Vercel**
- Environment variables secured using `.env` files
